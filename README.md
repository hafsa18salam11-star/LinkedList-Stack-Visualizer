# LinkedList-Stack-Visualizer

This project is a Java-based visual tool that helps users understand how Linked Lists and Stack data structures work. Instead of just reading theory, users can see every operation happening live on screen with pointer arrows and memory addresses.

## What This Project Does

The visualizer supports four types of data structures — Singly Linked List, Doubly Linked List, Circular Linked List, and Stack. For each structure, the user can perform insert, delete, and search operations.

**Insert** — Add a new node at the beginning, middle, any specific position, or end of the list.

**Delete** — Remove a node from the beginning, middle, any specific position, or end of the list. The list also supports a clear option to remove all nodes at once.

**Search** — Enter any number in the search bar. If the number is found, the node highlights in red. If the number is not found, the system displays a not found message.

Every node also shows its memory address, which helps users understand how nodes are connected in memory.
